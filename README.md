A faster drop-in for csv-reader 1.0.0: reads broken CSV files exactly as the reference does — same columns, rows and errors on every case, including stray CRs, unterminated quotes, quote junk, short and long rows — but jumps between delimiters with indexOf instead of walking one character at a time, finds a CR in a field through one list of every CR position instead of searching past the field's end, and finds each record's line feed once and reuses it for every field of the record.

## Run it

```sh
MAKEFUN_INPUT_DIR=<input-dir> MAKEFUN_OUTPUT_DIR=<output-dir> node main.ts
```
