A faster drop-in for csv-reader 1.0.0: reads broken CSV files exactly as the reference does — same columns, rows and errors on every case, including stray CRs, unterminated quotes, quote junk, short and long rows — but jumps between delimiters with indexOf and splits clean records whole instead of walking one character at a time.

## Run it

```sh
MAKEFUN_INPUT_DIR=<input-dir> MAKEFUN_OUTPUT_DIR=<output-dir> node main.ts
```
